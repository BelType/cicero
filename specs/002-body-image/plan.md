**Survey.** The Gauge's walk (`takeReport`, `src/gauge.ts`) gave a top-level inline-level box `inline: true`, and the flow's procession (`blockChildrenOf(container)`) skips an inline atom. The Stonehand's walk (`walks`, `src/stonehand.ts`) reads no inline box. So the box was in no procession: the walk stopped at the first block below the edge, the cut fell before that block, and the box standing before it was on the page before, below its area, drawn on no page. The anonymous boxes the Gauge already builds (*the anonymous box is in the procession*) are built inside a box and only for a run holding a word; the measured flow itself is no box of the list, and a run of atoms has no word to address.

**Design.** In `takeReport`, after the walk: each maximal run of the measured flow's inline-level children whose members are all `holdsAtomsAlone` or a line break, one at least an atom, is read as one unit. Its first box is flipped to `inline: false`, marked `line`, and given the run's lines as its `rect`; the flow's procession is read with a predicate that keeps it. The Stonehand's `monolithic` answers true for `line`. A cut before the run is the bare path to its first element, a cut after it the next block's, so the driver, the address and the presentation are unchanged. `refuseBareContent` passes over `holdsAtomsAlone`.

**The line's extent.** Read off the blocks beside the run, since a line holding no text of the flow's own shows no strut: the bottom margin edge of the in-flow block before it, or the run's own top; the top margin edge of the in-flow block after it, or the run's own bottom; at the flow's end, the container's bottom, at most a line-height below the run.
